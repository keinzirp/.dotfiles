# dotfiles

Personal dotfiles.

## Configuration
- `stow --verbose --restow <path>`
- `stow --verbose --delete <path>`
- `mise bootstrap`
- `misc` is not a valid stow target

Ghostty: `stow --restow ghostty`, then open Ghostty. It uses Nushell's existing Zellij auto-start. Alacritty remains available.
